    What it does

    TRs Quantum Bomb Testing is a game about the Elitzur–Vaidman bomb tester. You inspect a crate of bombs. Some are live and some are duds, and the only sensor that can tell them apart sets off a live bomb the moment light reaches it. Classically, every test of a live bomb is an explosion. With the quantum tester you can prove a bomb is live while the photon never touches it: 25% of the time with the basic setup, and over 90% with the Zeno upgrade.

    Every outcome in the game is a real shot from a Qiskit circuit. Python runs the circuits and saves each shot to a pool; the game draws the next shot from the matching pool. This is the same quantum math, run on simulated qubits. The original experiments used real photons.

    Credits: the Elitzur–Vaidman bomb tester

    The idea is not ours. The bomb tester was proposed by Avshalom Elitzur and Lev Vaidman in 1993 and later demonstrated with real photons. The Zeno version that pushes the success rate toward 100% comes from Kwiat and colleagues.

    1. A. C. Elitzur and L. Vaidman, “Quantum mechanical interaction-free measurements,” Foundations of Physics 23, 987–997 (1993).
    2. P. Kwiat, H. Weinfurter, T. Herzog, A. Zeilinger and M. A. Kasevich, “Interaction-free measurement,” Physical Review Letters 74, 4763 (1995). The first photon demonstration, which also proposed the Zeno version.
    3. P. G. Kwiat, A. G. White, J. R. Mitchell, O. Nairz, G. Weihs, H. Weinfurter and A. Zeilinger, “High-efficiency quantum interrogation measurements via the quantum Zeno effect,” Physical Review Letters 83, 4725 (1999).

    The problem it explores

    A live bomb acts as a measurement. With a dud, the photon's two paths interfere at the second H gate and the detector always reads 0. A live bomb checks which path the photon took, which destroys the interference, so sometimes the detector reads 1. A dud can never produce that 1, so a 1 proves the bomb is live, and in that run the photon went the safe way.

    basic tester, live bomb: boom 50% · reads 1 (proven live) 25% · reads 0 (inconclusive) 25%

    The Zeno upgrade splits the test into N small rotations, ry(π/N), with a bomb check after each. A dud lets the rotations add up to path 1. A live bomb's checks keep finding path 0 and snapping the photon back, so it ends on 0 with no explosion. This is the quantum Zeno effect: frequent checks freeze the state.

    P_safe(N) = cos2N(π / 2N)  →  N = 2: 25% · N = 10: 78% · N = 25: 90.6% · N = 50: 95.2%

    Results

    Share of live bombs proven safely, and duds wrongly labelled live, from the mid-circuit tester on Qiskit Aer with 4,000 shots per point. Noise is a depolarizing error after every ry step. The classical tester proves 0% of live bombs safely.

    How to run

    On Qollab, press Run with the built-in simulator: the game appears above the console, and Python (shipped_data.py) hands it the shot pools. To run it yourself:

    pip install qiskit qiskit-aer
    python generate_pools.py   # writes pools.json
    python noise_study.py     # writes noise_results.json
    python -m http.server     # open localhost:8000

    Opening index.html straight from disk will not work, because the browser blocks fetch("pools.json") on file:// pages.
